# Plant AI v0.1.1

## 作品概要

Plant AIは、観葉植物「カポック」の状態を複数の観察値から考える、初心者向けの植物管理デモWebアプリです。

表層水分、根元水分、鉢重量変化、温度、湿度を同時に表示し、センサー同士が同じ方向を示しているかを確認します。結果は「乾燥」「水分あり」「湿りすぎ」「判断保留」と、初心者向けの日本語による複数の根拠で表示します。

本バージョンは実機を接続せず、手入力とデモデータだけでコンセプトを確認できる静的Webアプリです。現在はコンセプトデモであり、個体別学習は今後カポックの実測データを用いて実装します。

## 独自性

一般的な土壌水分チェッカーは1つの水分値だけで状態を判断します。Plant AIは、表面と根元の水分差、鉢重量の増減、室内環境を照らし合わせ、情報が一致しない場合は無理に結論を出さず「判断保留」と表示します。

特に次の場面を再現できます。

- 表面は乾いていても、根元には水分が残っている
- 表層と根元がともに乾き、鉢重量も大きく減っている
- 水分値だけが急変し、鉢重量は変わっていない
- 水やりによって表層・根元水分と鉢重量が同じ方向へ上昇する

画面の「判断の確からしさ」は、複数センサーの一致度を4段階で表す補助表示です。植物状態の科学的な予測精度や、水やりの正解率を示すものではありません。

## 現在できること

- 5種類の観察値を手動入力
- 表層・根元水分のスライダーと数値入力を同期
- 複数センサーの一致・一部一致・不一致を判定
- 4種類の状態と4段階の確からしさを表示
- 判断根拠を初心者向けの日本語で複数表示
- 4つの審査用デモシナリオをボタンで再現
- ランダムなデモデータを生成
- 現在の状態をlocalStorageへ記録
- 観察スナップショットを1件ずつ削除
- 保存した観察データをCSV形式で書き出し
- 旧版の単一水分履歴を読み替える互換処理
- スマートフォン向けレイアウト

## ローカルでの開き方

外部ライブラリやビルド作業は必要ありません。

1. このリポジトリをダウンロードします。
2. フォルダーを展開します。
3. `index.html`をブラウザで開きます。

直接開いたページがブラウザの制限で正常に動かない場合は、このフォルダーで簡易サーバーを起動します。

```bash
python -m http.server 8000
```

その後、ブラウザで次のURLを開きます。

```text
http://localhost:8000
```

## ファイル構成

- `index.html`: 画面構造と日本語表示
- `style.css`: スマートフォン優先の見た目
- `logic.js`: センサー一致度、状態、確からしさ、判断根拠の判定
- `sensor-adapters.js`: `DemoSensorAdapter`と審査用シナリオ
- `script.js`: 入力イベント、画面更新、履歴保存

判定ロジックは画面更新から分離しています。基準を変更するときは`logic.js`、デモ値を変更するときは`sensor-adapters.js`を確認してください。

## 主要デモ4種類の動作確認結果

| デモ | 入力・変化 | 確認結果 |
|---|---|---|
| 表面だけ乾燥 | 表層18%、根元58%、重量変化-4g | 「判断保留」「深さで不一致」「低い」 |
| 全体が乾燥 | 表層16%、根元20%、重量変化-86g | 「乾燥」「センサー一致」「高い」 |
| センサー不一致 | 表層水分だけが直前から60ポイント上昇、重量変化-2g | 「判断保留」「センサー不一致」「参考程度」 |
| 水やり変化 | 表層+48ポイント、根元+40ポイント、鉢重量+190g | 水やりによる変化の可能性を表示 |

ここで表示する「確からしさ」は、植物状態の予測精度ではありません。水分値と鉢重量など、現在得られているセンサー情報が同じ方向を示しているかを表す整合性の目安です。

## 今後の実機接続予定

将来はESP32へ次のセンサーを接続する予定です。

- 表層用・根元用の静電容量式土壌水分センサー
- ロードセルとHX711による鉢重量測定
- 温湿度センサー

実機接続では、`DemoSensorAdapter`と同じ読み取り形式を持つ`Esp32SensorAdapter`を追加します。表示と判定ロジックは変更せず、データ取得部分だけを交換できる設計です。

外部AI API、クラウド、カメラ診断、自動給水は現在の対象外です。実機接続後も、植物の状態を断定せず、ユーザーが葉や土を確認するための判断材料を提供します。

## GitHub Pagesでの公開

すべて相対パスのHTML、CSS、JavaScriptで構成しており、外部APIやサーバー処理を必要としないため、GitHub Pagesで公開できる構成です。

GitHubへリポジトリを送信した後、リポジトリの「Settings」→「Pages」で`main`ブランチのルートを公開元に指定します。CSV出力とlocalStorageはブラウザ内で動作します。

## 注意事項

- 判定基準とデモ値はコンセプト確認用の暫定値です。
- 植物、鉢、土、季節、センサー位置によって適切な値は変わります。
- 実際の葉、土、鉢底、受け皿の状態も確認してください。
- 本アプリの表示だけで水やりを断定しないでください。
- 履歴は現在のブラウザのlocalStorageへ保存され、別端末とは共有されません。
