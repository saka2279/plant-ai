# Plant AI v0.2.0 センサー測定記録

## 記録の目的

ELEGOO UNO R3のA0で取得した土壌水分センサーの生値を比較し、空気中、乾いた土、湿った土、センサー未接続で値がどのように変わるかを確認します。

ここに記録する値は0〜1023のADC生値であり、実際の水分率ではありません。水分率への換算は、センサー個体、土、鉢、電源電圧ごとの校正が完了するまで行いません。
