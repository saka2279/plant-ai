# 飯塚市の地域課題と土みる帳

この文書は、土みる帳（つちみるちょう） v0.3.2リリース候補を「第15回e-ZUKAスマートアプリコンテスト2026」の農業分野へ応募するにあたり、飯塚市の公式資料で確認できる事実、開発者による分析、実装済みの内容、動作確認済みの範囲、今後検証する仮説を分けて整理したものです。

## 1. 事実

### 飯塚市の農業に関する統計

飯塚市「統計いいづか2024」には、次の数値が掲載されています。

| 指標 | 2010年 | 2020年 |
| --- | ---: | ---: |
| 総農家数 | 1,678戸 | 1,277戸 |
| 農家の世帯員数 | 5,083人 | 3,175人 |
| 経営耕地のある実経営体数 | 1,336 | 1,011 |

ただし、2020年には集計区分などの変更があります。「統計いいづか2024」では、農家の世帯員数について、2015年までは販売農家の年齢別世帯員数、2020年からは農業経営体（個人経営体）の年齢階層別世帯員数を引用したと注記されています。また、2020年から専業・兼業の調査項目が削除され、経営耕地に関する表では集計区分変更に伴い過去分も修正されています。そのため、2010年と2020年の数値は、定義や区分の違いに注意して扱う必要があります。

### 飯塚市の地域計画

飯塚市「地域計画」は、農業者の減少や高齢化などにより、地域の農地が適切に利用されなくなることへの懸念を示しています。そのうえで、地域の農地を次の世代へ引き継ぐため、農地利用の将来像を地域の関係者が一体となって考える地域計画を進めています。

### コンテストの募集テーマ

飯塚市「第15回e-ZUKAスマートアプリコンテスト2026」の一般の部では、「経済（地域経済・観光・農業）」を含む分野から地域課題を分析し、創造的・独創的で市民生活の向上につながるアプリを提案することが求められています。

## 2. 開発者による分析

ここからは、上記の公式資料を踏まえた開発者による分析です。

公表値では、表に挙げた3つの指標はいずれも2020年の値が2010年の値を下回っています。一方で、2020年には集計区分などの変更があるため、数値の差をそのまま同じ定義による減少幅として扱うことはできません。それでも、飯塚市自身が地域計画で農業者の減少と高齢化を課題として示していることから、農業を始める人や経験の浅い人が、日々の測定・観察・記録・振り返りを始める入口を検討する意義があると考えます。

土みる帳が直接扱うのは、農地全体の管理や農業者数の増加ではありません。植物を育てるときに繰り返す「測る、観察する、記録する、変化を見る、理由を振り返る」という小さな学習過程です。この入口を分かりやすくすることが、家庭や学習の場から栽培へ関心を持つ人を支える一つの方法になり得ると分析しています。

## 3. 実装済み

土みる帳 v0.3.2リリース候補では、「土壌センサーの値と観察を、同じ時刻に残す」という方針で、次の流れを実装しています。

1. ELEGOO UNO R3のA0で測定した0〜1023のADC生値について、20回分の`raw_avg`、`raw_min`、`raw_max`をUSBシリアルへ出力する。
2. Arduino IDEのシリアルモニター出力を複数行のままWeb画面へ貼り付け、後ろから探した最新の完全な測定行を採用する。不完全な測定行しかない場合は、不足している項目名を表示する。
3. 抽出した3つのraw値と測定日時を保存前に確認する。測定日時にはブラウザの現在時刻を初期入力し、利用者が修正できる。
4. 必要な場合だけ詳細項目を開き、水やり、土の感触、メモを追加する。水やりと土の感触は自動推定せず、初期値を「未確認」とする。
5. 測定日時、ADC生値、水やり、土の感触、メモを同じ実測記録としてlocalStorageへ保存し、一覧と`raw_avg`の時系列グラフで変化を振り返る。
6. 保存済み実測記録を既存フォームへ読み込み、同じIDのまま内容を更新する。編集はキャンセルでき、測定日時を変更した場合は一覧の並び順と時系列グラフを更新する。
7. ルールベースの判断デモは実測機能と分離し、初期状態では閉じて表示する。デモ内の複数観察値は仮想値であり、実機で複数センサーを取得していることを意味しない。

USBシリアルからブラウザへ直接取り込む機能ではなく、利用者がシリアルモニター出力を貼り付け、抽出結果を確認して保存する方式です。判断デモは機械学習済みモデルではなく、複数の仮想観察値を照らし合わせて判断保留や理由を示すルールベースの機能です。

## 4. 動作確認済み

実機UNO R3の次の出力をPlant AI v0.3.0へ貼り付け、最新の完全な測定行として解析できることを確認しています。

```text
uptime_ms=11008,raw_avg=410.0,raw_min=409,raw_max=410,samples=20
```

抽出された`raw_avg 410.0`、`raw_min 409`、`raw_max 410`を確認し、2026-08-01 05:37の実測記録として保存して、保存済み記録の一覧と時系列グラフへ反映できました。また、1366×768では貼り付けから保存までスクロールせず操作でき、360px幅では横スクロールが発生しないことを確認しています。

## 5. 開発者の仮説（今後の検証対象）

以下は今後の実測と利用者検証が必要な仮説であり、現時点で効果が確認された事実ではありません。

- 初心者がADC生値だけを見ず、水やりの有無、土の感触、時系列変化を一緒に記録すれば、センサーだけに頼らず植物を観察する習慣を身につけやすくなる。
- 同じ鉢の記録を続ければ、利用者がその鉢の変化に気づき、判断理由を振り返りやすくなる。
- 一鉢での小さな学習体験を検証し、対象や環境に合わせて改善すれば、家庭菜園、学校菜園、育苗、新規就農者の小規模栽培に応用できる可能性がある。

## 6. 未検証の範囲

- 現在はカポックを使った一鉢規模のコンセプト実証で、農業現場で検証済みの仕組みではない。
- ADC生値はセンサーの読み取り値であり、校正なしに土壌水分率として扱うことはできない。
- 植物の種類、鉢、土、季節などが変わった場合の有効性は確認できていない。
- 記録や表示だけで水やりの正解を断定することはできず、実際の土や葉の観察が必要である。
- 農業者減少の改善、収量向上、作業時間削減を示す実証結果はない。

## 7. 段階的な検証構想

まずカポック一鉢で記録を重ね、ADC生値、水やり、土の感触、時系列変化の組み合わせが、利用者の振り返りに役立つかを確認します。その後、対象ごとに測定条件と判断基準を検証しながら、次の順に小規模な利用場面への展開を検討します。

1. 家庭菜園での栽培記録
2. 学校菜園でのセンサー学習と栽培記録
3. 育苗時の観察支援
4. 新規就農者が始める小規模栽培での観察補助

これらは構想であり、効果を保証するものではありません。土みる帳は農業者の減少そのものを解決すると断定せず、経験の浅い人が測定・観察・記録・振り返りを始める入口として、どこまで役立てられるかを段階的に確かめます。
