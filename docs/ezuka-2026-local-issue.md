# 飯塚市の地域課題とPlant AI

この文書は、Plant AI v0.2.1を「第15回e-ZUKAスマートアプリコンテスト2026」の農業分野へ応募するにあたり、飯塚市の公式資料で確認できる事実と、Plant AI側の分析・仮説を分けて整理したものです。

## 1. 事実

### 飯塚市の農業に関する統計

飯塚市「統計いいづか2024」には、次の数値が掲載されています。

| 指標 | 2010年 | 2020年 |
| --- | ---: | ---: |
| 総農家数 | 1,678戸 | 1,277戸 |
| 農家の世帯員数 | 5,083人 | 3,175人 |
| 経営耕地のある実経営体数 | 1,336 | 1,011 |

ただし、2020年には集計区分などの変更があります。「統計いいづか2024」では、農家の世帯員数について、2015年までは販売農家の年齢別世帯員数、2020年からは農業経営体（個人経営体）の年齢階層別世帯員数を引用したと注記されています。また、2020年から専業・兼業の調査項目が削除され、経営耕地に関する表では集計区分変更に伴い過去分も修正されています。そのため、2010年と2020年の数値は、定義や区分の違いに注意して扱う必要があります。

### 飯塚市の地域計画

飯塚市「地域計画」は、農業者の減少や高齢化などにより、地域の農地が適切に利用されなくなることへの懸念を示しています。そのうえで、地域の農地を次の世代へ引き継ぐため、農地利用の将来像を地域の関係者が一体となって考える地域計画を進めています。

### コンテストの募集テーマ

飯塚市「第15回e-ZUKAスマートアプリコンテスト2026」の一般の部では、「経済（地域経済・観光・農業）」を含む分野から地域課題を分析し、創造的・独創的で市民生活の向上につながるアプリを提案することが求められています。

## 2. 分析

ここからは、上記の公式資料を踏まえたPlant AI開発者の分析です。

公表値では、表に挙げた3つの指標はいずれも2020年の値が2010年の値を下回っています。一方で、2020年には集計区分などの変更があるため、数値の差をそのまま同じ定義による減少幅として扱うことはできません。それでも、飯塚市自身が地域計画で農業者の減少と高齢化を課題として示していることから、農業を始める人や経験の浅い人が、日々の観察と判断の理由を学びやすくする仕組みを検討する意義があると考えます。

Plant AIが直接扱うのは、農地全体の管理ではなく、植物を育てるときに繰り返す「観察し、記録し、判断する」という小さな学習過程です。この入口を分かりやすくすることが、家庭や学習の場から栽培へ関心を持つ人を支える一つの方法になり得ると分析しています。

## 3. 仮説

以下は今後の実測と利用者検証が必要な仮説であり、現時点で効果が確認された事実ではありません。

- 初心者がADC生値だけを見ず、水やりの有無、土の感触、時系列変化を一緒に記録すれば、センサーを盲信せずに植物を観察する習慣を身につけやすくなる。
- 同じ鉢の記録を続ければ、その鉢がどのように乾いていくかという傾向に気づき、判断理由を振り返りやすくなる。
- 鉢植えでの小さな学習体験を検証し、対象や環境に合わせて改善すれば、家庭菜園、育苗、学校菜園、新規就農者の小規模栽培に応用できる可能性がある。

## 4. Plant AIの解決方法

Plant AIは、初心者の水やり判断を支援するため、次の流れを提供します。

1. センサーから得た0〜1023のADC生値を、土壌水分率へ変換せずに記録する。
2. 測定日時、ADC生値の平均・最小・最大、水やりの有無、土の感触、メモを同じ観察記録として残す。
3. 記録を時系列で表示し、水やりを行った時点と、その前後のADC生値の変化を振り返れるようにする。
4. デモでは複数の観察値が一致しない場面を再現し、単一センサーだけで結論を出さず「判断保留」や判断根拠を表示する。
5. 鉢ごとの乾燥傾向を記録し、利用者が「なぜその判断になったか」を学べる形を目指す。

現在のPlant AIは、あらかじめ定めた判定ロジックと記録・可視化によるコンセプトデモです。機械学習済みAIではありません。

## 5. 現在の限界

- 現在はカポックを使った鉢植え規模のコンセプト実証（デモと実測記録）の段階で、農業現場で検証済みの仕組みではない。
- ADC生値はセンサーの読み取り値であり、校正なしに土壌水分率として扱うことはできない。
- 植物の種類、鉢、土、季節などが変わった場合の有効性は確認できていない。
- 記録や表示だけで水やりの正解を断定することはできず、実際の土や葉の観察が必要である。
- 収量の改善や、農業者の減少という地域課題の解決を示す実証結果はない。

## 6. 将来展開

まずカポックの鉢植えで記録を重ね、ADC生値、水やり、土の感触、時系列変化の組み合わせが初心者の振り返りに役立つかを確認します。その後は、対象ごとに測定条件と判断基準を検証しながら、次の小規模な利用場面への展開を検討します。

- 家庭菜園での栽培記録
- 育苗時の観察支援
- 学校菜園でのセンサー学習と栽培記録
- 新規就農者が始める小規模栽培での観察補助

これらは将来の検証候補であり、現時点で効果を保証するものではありません。Plant AIは農業者の減少そのものを解決すると断定せず、初心者が観察と判断理由を学ぶ入口として、どこまで役立てられるかを段階的に確かめます。
